# Keepstorm

**Build the line. Break the keep.**

Keepstorm is an original browser lane-strategy prototype. Raise enchanted Musterworks, let them automatically create companies, counter the rival material cycle, and break the opposing Heartkeep.

## Play the current slice

```bash
npm install
npm run dev
```

Open `http://localhost:3000` and choose **Begin solo skirmish**.

### Controls

- `1` — build a Kilnward
- `2` — build a Windlass
- `3` — build a Prism Well
- `Space` — cast Stormbreak once it is ready
- `P` or `Escape` — pause

## What is implemented

- One complete solo match against an adaptive rival
- Three automatic company types with a readable counter cycle
- Coin, recurring Levy income, production timers, and an eight-work limit
- Automatic movement, targeting, keep defense, damage, and victory resolution
- A one-use Stormbreak comeback power
- Responsive title, battlefield, command deck, pause, and result states
- Pure deterministic engine functions with focused tests

The multiplayer and WebSocket design is documented in [docs/architecture.md](docs/architecture.md). The original setting and art direction live in [docs/creative-direction.md](docs/creative-direction.md).
